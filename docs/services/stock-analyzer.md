# 📈 Stock Analyzer (Sniper Engine v3.1)

> **Motto:** "Quantified logic, aggressive profits."
> **Role:** The intelligence layer of the Finance Tracker ecosystem.

## 🚀 Overview
Stock Analyzer is a high-fidelity quantitative analysis tool that combines technical indicators with XGBoost-based machine learning (SNIPER) to deliver high-conviction trading signals. It is optimized for both **Local TUI** use and **Remote Dashboard** access.

## 🏗️ Architecture (Clean & Modular)
The system follows a strict linear pipeline to ensure data integrity and testability:
1. **Fetch:** dapters/fetcher.py (yfinance + tenacity retries)
2. **Indicator:** dapters/indicators.py (EMA, RSI, MACD, OBV, Divergences)
3. **Score:** domain/scoring.py (10-point confluence additive model)
4. **Sniper:** dapters/ml_engine.py (XGBoost refinement)
5. **Output:** main.py (Rich TUI) or web_app.py (Plotly Dashboard)

## 📊 Core Scoring Logic (10.0 Scale)
- **Trend (3.0 pts):** EMA 50/200 Relationship + Price vs Baseline.
- **Momentum (3.0 pts):** RSI > 50, MACD Histogram, Signal Crossover.
- **Volume (2.0 pts):** Volume > MA20, Positive OBV Slope.
- **Divergence (2.0 pts):** Detection of Bullish RSI Divergences.

## 🎯 ML Sniper (Adaptive Inference)
The engine uses pre-trained XGBoost models (*.json) to categorize tickers into:
- **BUY:** High conviction trend starts.
- **NEUTRAL:** Sideways or high-noise zones.
- **SELL:** Breakdown or trend exhaustion.
