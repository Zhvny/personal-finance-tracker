# 🧠 Stock ML Training Suite (Braver Sniper v2.1)

> **Motto:** "Filter the Trash, Hunt the Alpha."
> **Role:** The "Brain Factory" - Training and evaluation environment for ML Sniper models.

## 🚀 Overview
Stock ML is the core research and training environment for the ecosystem's machine learning models. It implements the **"Braver Sniper" (v2.1)** logic, which features a **Thin Neutral Zone (0.1x ATR)** to maximize signal aggressiveness while maintaining a **90% Precision Lock** for high-conviction signals.

## 🔬 The "Braver Sniper" Logic (v2.1)
Unlike standard models that get stuck in "Neutral" zones, the Braver Edition:
- **Neutral Barrier:** Reduced from 0.4x ATR to **0.1x ATR**.
- **Sniper Threshold:** Hard-coded to **≥ 0.90 conviction** to ensure 90% accuracy.
- **Feature Set:** 27-vector microstructure indicators (MFI, ADX, CCI, OBV, etc.).
- **Volume Filter:** Requires a **> 1.8x Volume Spike** for SNIPER confirmation.

## 🏗️ Core Pipeline (01 to 09 Scripts)
1. **01_data_acquisition.py:** Bulk fetching from yfinance/FRED.
2. **02_feature_engineering.py:** Computes 27 indicators + Triple Barrier Labeling.
3. **07_upgraded_system.py:** **(MAIN)** Trains XGBoost models and performs an "Honest Audit" (80/20 walk-forward split).
4. **08_generate_dashboard.py:** Generates the index.html visual audit report.
5. **09_stability_check.py:** Stress-tests model predictions against historical drift.
